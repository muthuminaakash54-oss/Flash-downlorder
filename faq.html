Can HTML/CSS/JS alone download YouTube, Facebook and TikTok videos?

Not reliably. The browser front end needs a server-side processor or an authorized API because of cross-origin restrictions, protected media delivery and platform-specific behavior.

Where do I connect my backend?

Open app.js and set API_ENDPOINT to your own service. The front end sends the URL and selected format as JSON.

Can I host this on GitHub Pages?

Yes, the static front end can be hosted there. Your media-processing API must be hosted separately and configured with suitable CORS rules.

Is downloading any online video allowed?

No. Rights and platform terms vary. Only process content you are legally allowed to save.
